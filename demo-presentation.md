## Слайд 1: Что такое opencode-plugin-kafka?

### Определение
Это **плагин-коннектор**, который связывает **Apache Kafka** с **OpenCode AI Agent**.

### Основная задача
Автоматическая обработка задач из Kafka-топиков через AI-агента:
- Читает задачи из Kafka
- Передает задачи AI-агенту
- Возвращает результаты обратно в Kafka
- При ошибках — пишет в Dead Letter Queue (DLQ)

### Кому нужен:
- Команды, использующие Kafka для асинхронной обработки
- Нужен AI-агент для анализа/генерации контента
- Требуется надежная обработка ошибок

### Компоненты:

| Компонент | Описание |
|----------|----------|
| **Kafka Consumer** | Читает из `opencode.prompts` |
| **Router** | JSONPath маршрутизация → выбирает правило |
| **Prompt Builder** | Собирает промпт из шаблона |
| **AI Agent** | Выполняет задачу |
| **Response Producer** | Пишет ответ в `opencode.responses` |
| **DLQ Handler** | Пишет ошибки в `opencode.dlq` |

## Слайд 3: Сценарии демонстрации

### Сценарий A: "Простой publish/consume"

**Цель:** Показать базовую работоспособность

```bash
# Запустить демо
KAFKA_BROKERS=localhost:9093 node scripts/demo-simple.mjs
```

**Вывод:**
```
✅ Producer подключен к Kafka
✅ Сообщение отправлено в opencode.prompts
✅ Прочитано 1 сообщений из opencode.prompts
✅ Демо завершено успешно!
```

**Что видно:**
- Kafka принимает сообщения
- Consumer читает сообщения
- Топик работает

---

### Сценарий B: "E2E flow с AI"

**Цель:** Показать полный цикл обработки

```bash
KAFKA_BROKERS=localhost:9093 node scripts/demo-e2e-flow.mjs
```

**Что происходит:**
1. Producer отправляет задачу code_review
2. Plugin читает задачу из топика
3. Router выбирает правило по JSONPath
4. Строится промпт для AI
5. AI выполняет код-ревью
6. Результат пишется в responses топик

**Требования:**
- Настроенный AI Agent (mock в dev-режиме)
- Правила маршрутизации в `.opencode/kafka-router.json`

---

### Сценарий C: "Обработка ошибок"

**Цель:** Показать надежность

```bash
# Отправить невалидное сообщение
# Plugin напишет в DLQ
```

**Что видно:**
- При ошибке парсинга → в DLQ
- При таймауте AI → в DLQ
- При ошибке валидации → в DLQ
- Все сообщения обрабатываются, ничего не теряется

## Слайд 4: Production use cases

### 1. Асинхронный Code Review
- Задачи на code review кладутся в Kafka
- AI обрабатывает в порядке очереди
- Результаты возвращаются в Kafka
- CI/CD интегрируется через webhook

### 2. Автоматическое тестирование
- AI генерирует тесты для PR
- Результаты прогоняются в CI
- Отчеты пишутся в Kafka

### 3. Document Generation
- Генерация документации из кода
- Параллельная обработка десятков файлов
- Масштабируется через партиции Kafka

### 4. Refactoring
- Массовый рефакторинг легаси-кода
- AI.apply → в result топик
- Человек проверяет и применяет

## Слайд 5: Преимущества

### Почему это надежно:

| Фича | Описание |
|------|----------|
| **DLQ** | Ошибки не теряются — всегда попадают в DLQ |
| **Strict Init** | Падение при не��алидном конфиге — надежный старт |
| **Offset Commit** | После успешной обработки — гарантия доставки |
| **Graceful Shutdown** | Корректное завершение без потерь |

### Почему это удобно:

- **JSONPath маршрутизация** — гибкие правила
- **Шаблонизация промптов** — ${$.field} подстановка
- **Multiple topics** — до 5 топиков на plugin
- **DLQ envelope** — полная информация об ошибке
